# Портфолио Полины Заец (Астаховой)

[Открыть портфолио](https://pollinka54-collab.github.io/portfolio/)

## Локальный запуск

```sh
npm ci
npm run dev
```

Сборка для GitHub Pages создаёт готовый HTML и сохраняет интерактивные разделы. GitHub Actions публикует изменения из ветки `main`. Тексты находятся в `src/content`, изображения и видео в `public/assets`.
